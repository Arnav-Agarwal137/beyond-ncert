# Study Tools

Single-file web pages I built for myself while preparing for **NEET** and then
while learning things that were not on any syllabus. No build step, no
dependencies, no server — open the file and it works.

**Live: see the Pages link on this repository.**

| Tool | What it is |
|---|---|
| **[Beyond NCERT](beyond-ncert/)** | Curriculum explorer — the whole syllabus, searchable, with progress kept between visits. The largest of these: ~327 KB, 113 functions, 21 breakpoints |
| **[The Grand Revision](beyond-ncert/grand-revision.html)** | Everything learned, then the first paper — a two-day revision pass |
| **[The Recut](the-recut/)** | The same month compressed into one ten-hour run, cut like a broadcast edit timeline |
| **[Relativity Explorer](relativity-explorer/)** | Special and general relativity, and **how we know** — 119 functions and two canvases of interactive diagrams |
| **[The Free AI Stack](free-ai-stack/)** | 21 days, everything Claude, ₹0 for the rest |
| **[Virtual Cell Plate Map](virtual-cell-plate-map/)** | A guide to the Arc Institute Virtual Cell Challenge, laid out as a **96-well microplate** — each unit is a well, and reading it develops the well |
| **[The Big Menu](the-big-menu/)** | 26 things to build at home that do what you tell them |
| **[India Science Events](india-science-events/)** | Where the science actually happens in India, and when |

## Why they look different from each other

Every one of these wears a visual language nothing else does — a broadcast edit
timeline, a microplate on a plate-reader deck, an engraved brass instrument.
That is deliberate, and it is a rule I set myself: **a new page never reuses the
look of an old one.**

The constraint is not decoration. Two tests have to pass together — the form has
to **fit** what the content actually is, and it has to be one I have not used
before. A striking design that does not fit is a failure, not a bold swing.

## They are single files, and that is the point

Each is one `.html` with its CSS and JavaScript inside it. That means:

- It works offline, forever, with no install.
- It survives a laptop change, a framework going out of fashion, and me.
- You can read the whole thing.

State — what you have ticked, where you got to, light or dark — is kept in
`localStorage`, so it is per-browser and yours alone. Nothing is uploaded
anywhere.

Most of these are shaped around **my** syllabus, my exam, my gaps, my state's

**If you want one built around your situation — your syllabus, your exam, your
